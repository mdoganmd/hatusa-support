Hatusa 隱私權政策

上次更新：2026 年 10 月 20 日

Hatusa 在您的電腦上執行。Hatusa 本身不會建立任何網路連線，沒有帳戶、廣告、分析或遙測，也不會傳送任何資料給開發人員。

Windows 元件

Hatusa 的視窗由 Microsoft Edge WebView2 繪製，而 WebView2 是 Windows 的一部分。與其他 Windows 元件一樣，無論您的設定為何，WebView2 都會將必要診斷資料傳送給 Microsoft；選用診斷資料則只有當您在 Windows 診斷資料設定中允許時才會傳送。這部分適用 Microsoft 隱私權聲明，而非 Hatusa 的隱私權政策。在 Microsoft Store 版本中，Windows 會透過 Microsoft Store 服務檢查您的授權；Hatusa 本身仍不會建立任何網路連線。Hatusa 中的連結（本政策、支援頁面）會在您的網頁瀏覽器中開啟。

Hatusa 在您的電腦上儲存的內容

為了記住您的選擇，Hatusa 會在其 AppData 資料夾中保留一個設定檔。其中包含顯示器識別碼（根據每台顯示器回報的製造商與型號產生，若有序號也會納入）、您為顯示器和輸入來源設定的名稱、您的亮度排程以及您的喜好設定。如果您開啟選用的錯誤記錄（預設為關閉），警告與錯誤會寫入最多 2 MB 的記錄檔（Microsoft Store 版本：位於應用程式本身的套件資料夾中；其他版本：%LOCALAPPDATA%\Hatusa\logs）。

哪些內容會離開您的電腦

Hatusa 不會傳送任何內容。「複製診斷資訊」會將一份報告複製到剪貼簿；報告包含顯示器型號、連線類型與 DDC/CI 回應（序號已遮蔽），如果錯誤記錄已開啟，也會包含記錄的最新部分。只有在您自行將其貼到某處（例如支援要求中）時才會被分享。GitHub 上的支援要求是公開的。

由您掌控

您可以隨時在 Hatusa 中變更或刪除名稱與喜好設定。解除安裝 Microsoft Store 版本會移除其套件資料夾中保留的設定與記錄。如果先前曾在同一台電腦上安裝 Hatusa 的另一個（非 Store）版本，其設定檔會由兩個版本共用，並在解除安裝後保留。

兒童

Hatusa 不會向任何人（包括兒童）收集個人資訊。

變更與聯絡方式

本政策的變更將在此頁面上公布。如有疑問：github.com/mdoganmd/hatusa-support/issues。
