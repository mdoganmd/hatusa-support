Politique de confidentialité de Hatusa

Dernière mise à jour : 20 octobre 2026

Hatusa s’exécute sur votre PC. Hatusa n’établit lui-même aucune connexion réseau ; il n’a ni compte, ni publicité, ni outil d’analyse, ni télémétrie, et n’envoie aucune donnée au développeur.

Composants Windows

La fenêtre de Hatusa est affichée par Microsoft Edge WebView2, un composant de Windows. Comme les autres composants Windows, WebView2 envoie à Microsoft les données de diagnostic obligatoires quels que soient vos paramètres, et les données de diagnostic facultatives uniquement si vous les autorisez dans les paramètres de données de diagnostic de Windows ; cela relève de la Déclaration de confidentialité Microsoft, et non de Hatusa. Dans la version Microsoft Store, Windows vérifie votre licence auprès du service Microsoft Store ; Hatusa lui-même n’établit toujours aucune connexion réseau. Les liens de Hatusa (cette politique, la page d’assistance) s’ouvrent dans votre navigateur web.

Ce que Hatusa enregistre sur votre PC

Pour mémoriser vos choix, Hatusa conserve un fichier de paramètres dans son dossier de données d’application. Il contient des identifiants de moniteur (construits à partir du fabricant, du modèle et, s’il est disponible, du numéro de série, tels que chaque moniteur les communique), les noms que vous donnez aux moniteurs et aux entrées, votre planification de la luminosité et vos préférences. Si vous activez le journal des erreurs facultatif (désactivé par défaut), les avertissements et les erreurs sont écrits dans un fichier journal de 2 Mo au maximum (version Microsoft Store : dans le dossier de package propre à l’application ; autre version : %LOCALAPPDATA%\Hatusa\logs).

Ce qui quitte votre PC

Hatusa n’envoie rien. « Copier le diagnostic » copie un rapport dans le Presse-papiers ; il contient les modèles de moniteur, les types de connexion et les réponses DDC/CI, avec les numéros de série masqués, et, si le journal des erreurs est activé, sa partie la plus récente. Il n’est partagé que si vous le collez vous-même quelque part, par exemple dans une demande d’assistance — les demandes d’assistance sur GitHub sont publiques.

Vous gardez le contrôle

Vous pouvez modifier ou supprimer les noms et les préférences dans Hatusa à tout moment. La désinstallation de la version Microsoft Store supprime les paramètres et les journaux conservés dans son dossier de package. Si l’autre version de Hatusa (hors Store) a été installée auparavant sur le même PC, son fichier de paramètres est utilisé par les deux versions et reste en place après la désinstallation.

Enfants

Hatusa ne collecte aucune information personnelle auprès de quiconque, y compris des enfants.
