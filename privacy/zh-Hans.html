Hatusa 隐私政策

上次更新：2026 年 10 月 20 日

Hatusa 在你的电脑上运行。Hatusa 本身不建立任何网络连接，没有帐户、广告、分析或遥测，也不会向开发者发送任何数据。

Windows 组件

Hatusa 的窗口由 Windows 的组成部分 Microsoft Edge WebView2 绘制。与其他 Windows 组件一样，无论你如何设置，WebView2 都会向 Microsoft 发送必需的诊断数据；只有当你在 Windows 诊断数据设置中允许时，才会发送可选诊断数据。这部分受 Microsoft 隐私声明约束，而非 Hatusa。在 Microsoft Store 版本中，Windows 会通过 Microsoft Store 服务检查你的许可证；Hatusa 本身仍不建立任何网络连接。Hatusa 中的链接（本政策、支持页面）会在你的 Web 浏览器中打开。

Hatusa 在你的电脑上存储的内容

为了记住你的选择，Hatusa 会在其应用数据文件夹中保存一个设置文件。其中包含显示器标识符（根据每台显示器报告的制造商、型号及可用时的序列号生成）、你为显示器和输入源设置的名称、你的亮度计划以及你的偏好设置。如果你打开可选的错误日志（默认关闭），警告和错误会写入一个最大 2 MB 的日志文件（Microsoft Store 版本：位于应用自己的包文件夹中；其他版本：%LOCALAPPDATA%\Hatusa\logs）。

哪些内容会离开你的电脑

Hatusa 不会发送任何内容。“复制诊断信息”会将一份报告复制到剪贴板；报告包含显示器型号、连接类型和 DDC/CI 响应（序列号已遮盖），如果错误日志已打开，还包含日志的最新部分。只有当你自己将其粘贴到某处（例如支持请求中）时，它才会被共享。GitHub 上的支持请求是公开的。

由你掌控

你可以随时在 Hatusa 中更改或删除名称和偏好设置。卸载 Microsoft Store 版本会删除其包文件夹中保存的设置和日志。如果此前在同一台电脑上安装过 Hatusa 的另一个（非 Store）版本，其设置文件由两个版本共同使用，并在卸载后保留。

儿童

Hatusa 不会收集任何人（包括儿童）的个人信息。

变更与联系
