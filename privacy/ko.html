Hatusa 개인정보 처리방침

최종 업데이트: 2026년 10월 20일

Hatusa는 사용자의 PC에서 실행됩니다. Hatusa 자체는 네트워크에 연결하지 않으며, 계정, 광고, 분석 도구, 원격 분석이 없고, 개발자에게 어떤 데이터도 보내지 않습니다.

Windows 구성 요소

Hatusa의 창은 Windows의 일부인 Microsoft Edge WebView2가 그립니다. 다른 Windows 구성 요소와 마찬가지로 WebView2는 필수 진단 데이터를 설정과 관계없이 Microsoft에 보내며, 선택적 진단 데이터는 Windows 진단 데이터 설정에서 허용한 경우에만 보냅니다. 이는 Hatusa가 아니라 Microsoft 개인정보처리방침의 적용을 받습니다. Microsoft Store 버전에서는 Windows가 Microsoft Store 서비스를 통해 라이선스를 확인하며, 이때도 Hatusa 자체는 네트워크에 연결하지 않습니다. Hatusa의 링크(이 방침, 지원 페이지)는 웹 브라우저에서 열립니다.

Hatusa가 PC에 저장하는 정보

사용자가 선택한 내용을 기억하기 위해 Hatusa는 앱 데이터 폴더에 설정 파일을 보관합니다. 이 파일에는 모니터 식별자(각 모니터가 보고하는 제조업체, 모델 및 가능한 경우 일련번호를 기반으로 생성), 모니터와 입력에 지정한 이름, 밝기 예약, 기본 설정이 들어 있습니다. 선택 사항인 오류 로그를 켜면(기본값은 꺼짐) 경고와 오류가 최대 2 MB의 로그 파일에 기록됩니다(Microsoft Store 버전: 앱 자체의 패키지 폴더, 다른 버전: %LOCALAPPDATA%\Hatusa\logs).

PC 밖으로 나가는 정보

Hatusa는 아무것도 보내지 않습니다. "진단 정보 복사"는 보고서를 클립보드에 복사합니다. 보고서에는 모니터 모델, 연결 유형, DDC/CI 응답이 일련번호를 가린 상태로 포함되며, 오류 로그가 켜져 있으면 로그의 최근 부분도 포함됩니다. 보고서는 사용자가 직접 지원 요청 등에 붙여 넣을 때만 공유됩니다. GitHub에 등록한 지원 요청은 공개됩니다.

사용자 제어

이름과 기본 설정은 Hatusa에서 언제든지 변경하거나 삭제할 수 있습니다. Microsoft Store 버전을 제거하면 패키지 폴더에 보관된 설정과 로그가 삭제됩니다. 같은 PC에 이전에 Hatusa의 다른 버전(Store 외 버전)이 설치되어 있었다면, 그 설정 파일은 두 버전이 함께 사용하며 제거 후에도 남아 있습니다.

아동

Hatusa는 아동을 포함한 누구로부터도 개인정보를 수집하지 않습니다.
