Datenschutzerklärung von Hatusa

Zuletzt aktualisiert: 20. Oktober 2026

Hatusa läuft auf Ihrem PC. Hatusa selbst stellt keine Netzwerkverbindungen her, hat keine Konten, keine Werbung, keine Nutzungsanalyse und keine Telemetrie und sendet keine Daten an den Entwickler.

Windows-Komponenten

Das Fenster von Hatusa wird von Microsoft Edge WebView2 dargestellt, einem Bestandteil von Windows. Wie andere Windows-Komponenten sendet WebView2 erforderliche Diagnosedaten unabhängig von Ihren Einstellungen an Microsoft und optionale Diagnosedaten nur, wenn Sie dies in den Windows-Einstellungen für Diagnosedaten zulassen; dies fällt unter die Microsoft-Datenschutzbestimmungen, nicht unter die Datenschutzerklärung von Hatusa. In der Microsoft Store-Version prüft Windows Ihre Lizenz beim Microsoft Store-Dienst; Hatusa selbst stellt auch dann keine Netzwerkverbindungen her. Links in Hatusa (diese Datenschutzerklärung, die Supportseite) werden in Ihrem Webbrowser geöffnet.

Was Hatusa auf Ihrem PC speichert

Damit Hatusa sich Ihre Auswahl merken kann, legt es in seinem App-Datenordner eine Einstellungsdatei an. Sie enthält Monitorkennungen (gebildet aus Hersteller, Modell und, falls verfügbar, Seriennummer, wie vom jeweiligen Monitor gemeldet), die Namen, die Sie Monitoren und Eingängen geben, Ihren Helligkeitszeitplan und Ihre sonstigen Einstellungen. Wenn Sie das optionale Fehlerprotokoll einschalten (standardmäßig aus), werden Warnungen und Fehler in eine Protokolldatei von höchstens 2 MB geschrieben (Microsoft Store-Version: im eigenen Paketordner der App; andere Version: %LOCALAPPDATA%\Hatusa\logs).

Was Ihren PC verlässt

Hatusa sendet nichts. „Diagnosedaten kopieren“ kopiert einen Bericht in die Zwischenablage; er enthält Monitormodelle, Verbindungsarten und DDC/CI-Antworten mit maskierten Seriennummern und, wenn das Fehlerprotokoll eingeschaltet ist, dessen neuesten Teil. Er wird nur weitergegeben, wenn Sie ihn selbst irgendwo einfügen, zum Beispiel in eine Supportanfrage – Supportanfragen auf GitHub sind öffentlich.

Ihre Kontrolle

Sie können Namen und Einstellungen in Hatusa jederzeit ändern oder löschen. Beim Deinstallieren der Microsoft Store-Version werden die in ihrem Paketordner gespeicherten Einstellungen und Protokolle entfernt. Wenn auf demselben PC zuvor die andere Version von Hatusa (nicht aus dem Store) installiert war, wird deren Einstellungsdatei von beiden Versionen verwendet und bleibt nach der Deinstallation erhalten.

Kinder

Hatusa erhebt von niemandem personenbezogene Daten, auch nicht von Kindern.
