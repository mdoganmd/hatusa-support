# Hatusa support

Support and privacy policy for **Hatusa**, a Windows 11 tray app for controlling monitors.
This repository holds only the support page, the privacy policy and the issue forms; Hatusa's source code is not here.

- Support page: https://mdoganmd.github.io/hatusa-support/
- Report a problem: https://github.com/mdoganmd/hatusa-support/issues/new/choose (issues are public)
- Privacy policy: https://mdoganmd.github.io/hatusa-support/privacy/en.html
